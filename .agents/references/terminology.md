# Terminology

Use this file as the routing surface for shared vocabulary used by AI
agents in this repository.

Shared terminology is for harness, workflow, repository, and codebase
language. Blog-post-specific terminology belongs in the active blog
writing conversation and should only become shared terminology when it
is useful beyond one post.

## Dictionaries

- [General Dictionary Routing](dictionary/general.md): start here to
  decide which dictionary to load.

## Usage

Before adding or changing reusable AI guidance, check the relevant
dictionary and use its preferred terms. When new recurring terms emerge,
add them to the dictionary instead of redefining them across adapters,
skills, or references.

When writing a blog post, maintain a post-local terminology list for the
topic. Keep that list separate from shared harness terminology unless a
term is also needed for future AI workflow or codebase guidance.
