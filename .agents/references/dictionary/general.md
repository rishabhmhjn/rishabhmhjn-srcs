# General Dictionary Routing

Use this file to decide which dictionary to load before writing or
updating AI guidance, workflow instructions, or blog content.

## Load `harness.md`

Read [harness.md](harness.md) when work touches:

- `.agents/` source-of-truth guidance.
- tool adapters such as `AGENTS.md`, `CLAUDE.md`, or Copilot
  instructions.
- executable workflow skills.
- shared references.
- repo discovery and runtime discovery language.
- Nx workspace, Nx project, workspace package, or project boundary
  terminology.
- permanent worktrees, slot worktrees, recurring topic types, or topic
  branches.
- public or internal codebase surfaces.

## Load `blog.md`

Read [blog.md](blog.md) when work touches:

- blog post planning or drafting.
- blog slugs, post files, frontmatter, or content conventions.
- post-local terminology for one blog post.
- blog worktree or blog feature branch wording.

## Load Both

Read both dictionaries when a workflow crosses harness and blog
language, such as the `add-blog-post` skill or permanent worktree
guidance for blog branches.
